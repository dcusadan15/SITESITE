БЕСПЛАТНАЯ ПРОВЕРКА САЙТА И TELEGRAM НА RENDER

Этот архив содержит сайт и сервер отправки отзывов. Токена и других учётных данных в архиве нет.
Регистрировать домен и арендовать VPS для проверки не требуется.

1. ПОДГОТОВЬТЕ КОД
Распакуйте архив. Создайте репозиторий на https://github.com/new — можно Private.
Загрузите содержимое распакованной папки, сохранив папку public.
В корне репозитория должны быть package.json, server.mjs и папка public.
Не загружайте сам ZIP вместо файлов. Файл .env с настоящим токеном загружать нельзя.

2. СОЗДАЙТЕ СЕРВИС
Откройте https://dashboard.render.com/ и войдите или зарегистрируйтесь.
Выберите New → Web Service, подключите GitHub и выберите созданный репозиторий.
Параметры:
  Language: Node
  Branch: ваша ветка с кодом (обычно main)
  Root Directory: оставить пустым, если файлы лежат в корне репозитория
  Build Command: npm run check
  Start Command: npm start
  Instance Type: Free
Это должен быть Web Service, потому что для Telegram нужен работающий сервер.
Отдельная база данных или отдельный процесс бота для этого сайта не нужны.

3. ДОБАВЬТЕ ENVIRONMENT VARIABLES
В настройках окружения Render укажите:
  HOST = 0.0.0.0
  TELEGRAM_BOT_TOKEN = токен вашего бота из BotFather
  TELEGRAM_CHAT_ID = числовой ID вашего личного чата с ботом
PORT вручную задавать не нужно: Render предоставляет его сам.
Токен вводится только в Environment сервера, не в HTML, GitHub или настройки посетителя.

Если ID ещё неизвестен:
  На своём компьютере откройте бота, отправьте /start ещё раз.
  Запустите Start-local.cmd из распакованного архива и введите токен в скрытое поле.
  В консоли появится «Получатель отзывов: ... (ID ...)».
  Скопируйте только число ID в TELEGRAM_CHAT_ID на Render. Остановите локальный запуск Ctrl+C.
  Эта вспомогательная команда нужна только для получения ID; сайт будет работать на Render без включённого компьютера.

4. УКАЖИТЕ АДРЕС САЙТА
Нажмите Create Web Service и дождитесь Live.
Скопируйте точный HTTPS-адрес сервиса из Render, например https://your-name.onrender.com.
В Environment добавьте:
  PUBLIC_ORIGIN = этот адрес без завершающего слеша
Сохраните изменения с перезапуском/повторным развёртыванием сервиса.
До этого шага отправка может возвращать ошибку проверки адреса сайта.
Не подставляйте пример your-name вместо настоящего адреса.

5. ПРОВЕРЬТЕ
Откройте HTTPS-адрес Render на телефоне или компьютере.
В настройках страницы для нужной звезды выберите Telegram и сохраните.
Нажмите эту звезду, введите тестовый отзыв и нажмите кнопку отправки.
Успех должен появиться после принятия сообщения Telegram; затем проверьте личный чат с ботом.
Посетитель остаётся на сайте — открывать Telegram или вручную пересылать сообщение ему не требуется.
Для проверки переходов укажите точные ссылки на карточки Яндекса/2ГИС и выберите соответствующую площадку для звезды.
Настройки сайта хранятся в браузере. Для другого устройства используйте гостевую ссылку из настроек, которая переносит конфигурацию.

ОГРАНИЧЕНИЯ FREE
После 15 минут без входящих запросов сервис засыпает. Первое открытие после простоя занимает примерно минуту.
На рабочую область выделяется 750 часов бесплатных экземпляров в месяц, общих для всех бесплатных сервисов.
У трафика и сборок тоже есть лимиты. Без добавленной платёжной карты при исчерпании лимита сервисы/сборки приостанавливаются вместо списания оплаты.
Для тестирования этого достаточно; бесплатный тариф не рассчитан на постоянную рабочую эксплуатацию.
Перезапуск сбрасывает временную защиту от повторов и счётчики запросов; постоянного архива отзывов в этом проекте нет.

ЕСЛИ НЕ РАБОТАЕТ
Сервис не открывается: проверьте HOST=0.0.0.0 и Deploy Logs.
«Бот не подключён»: проверьте TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID.
Ошибка адреса запроса: PUBLIC_ORIGIN должен в точности совпадать с адресом открытого сайта, включая https, без слеша в конце.
Telegram не принял сообщение: отправьте /start именно этому боту, проверьте числовой ID и токен.
Проверяйте сайт по HTTPS-адресу Render; отдельный Otzyv.html на компьютере предназначен для просмотра.

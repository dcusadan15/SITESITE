Настройка страницы

Для каждой звезды выберите направление. Ссылки на площадки задаются ниже. При выборе Telegram отзыв отправляется из формы на сайте.

Куда открывать каждую оценку

Для направления Telegram откроется форма на сайте. Токен бота и получатель задаются только на сервере.

Настройки сохраняются в этом браузере. Ссылка для гостей содержит настройки заведения. Нажатие на звезду открывает площадку или форму сообщения владельцу. Прямые ссылки на публичные отзывы доступны до выбора звёзд. На сайте оценки не сохраняются. При заполненных настройках сервера сообщение из формы отправляется в Telegram без открытия приложения.
